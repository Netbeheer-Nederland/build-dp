= NBNL Modellen — Dataproducten

== Ontwikkel- en bouwomgeving


=== Publiceren nieuwe versie

Zorg dat je ingelogd bent:

[source,shell]
....
$ docker login
....

Met de repository root als current working directory, bouw de nieuwe image:

[source,shell]
....
$ docker build -t ghcr.io/netbeheer-nederland/build-dp:latest .
....

Push de nieuwe image naar GHCR:

[source,shell]
....
$ docker push ghcr.io/netbeheer-nederland/build-dp:latest
....
